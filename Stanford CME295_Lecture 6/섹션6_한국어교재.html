섹션 6. DeepSeek-R1 파이프라인과 distillation

📄원문 출처: Stanford CME295, Autumn 2025, Lecture 6, 타임스탬프 1:29:43~(1:47:02, 끝)

1. 강의 개요

  • 앞서 배운 기법들이 어떻게 모이는지를 DeepSeek-R1 논문으로 본다 — 먼저 R1-Zero(RL만), 다음 R1(전체 파이프라인).
  • R1-Zero의 한계(언어 혼합·가독성)와, 이를 해결한 R1의 다단계 파이프라인(cold start SFT → RL → 거부 샘플링 SFT → 최종 RL)을 다룬다.
  • 큰 추론 모델의 능력을 작은 모델로 옮기는 distillation(추론 사슬 생성 후 SFT)을 설명한다.

2. 학습 목표

  1. DeepSeek-R1-Zero가 무엇을 증명했고 어떤 한계가 있었는지 설명할 수 있다.
  2. R1의 다단계 파이프라인(cold start·언어 일관성 보상·거부 샘플링·최종 정렬)을 안다.
  3. 추론 모델의 distillation 방식(교사로 추론 사슬 생성 → 학생 SFT)을 이해한다.

한국어 번역

앞 기법들이 어떻게 합쳐지는지 DeepSeek 논문으로 봅니다. 먼저 R1-Zero(개념 증명)입니다.

기반 모델은 최신 아키텍처의 사전학습 모델입니다 — 전문가 혼합(MoE), DeepSeek-V2에서 도입한 다중 잠재 어텐션(MLA), 트랜스포머 블록의 pre-norm 등(앞 강의들에서 다룬 기법). 이 위에서 다음 토큰 예측으로 사전학습을 합니다.

여기서 핵심: SFT로 정렬하는 대신, 어떤 지도도 받지 않은(no supervision) 이 사전학습 모델에 곧바로 추론 데이터로 RL을 적용합니다. 보상은 ① 출력 답의 정답성 + ② 형식(<think> 토큰 사용)입니다. 논문은 학습 템플릿도 공개했는데 매우 단순합니다 — "너는 사용자와 대화하는 비서다, 생각은 <think>에 넣고 답은 답 블록에 넣어라" 정도입니다.

결과: 사전 지도 없이 이 보상만으로도 추론 벤치마크(AIME 등) 점수가 시간이 지나며 오릅니다. 다 해결된 것 같지만 — 추론 사슬을 보니 두 가지 문제가 있었습니다. ① 언어 혼합(서로 다른 언어를 섞음), ② 구문(syntax) 문제. 강한 지도 신호 없이 무엇이든 최적화하게 두었기에, 닻이 될 기준이 없어서로 추정됩니다.

한국어 번역

이제 전체 모델 R1입니다. R1-Zero의 한계(언어 혼합·가독성)를 다단계 파이프라인으로 해결합니다. DeepSeek-V3 기본 모델(비추론 사전학습 모델)에서 출발합니다.

  1. cold start SFT: 바로 RL을 하지 않고, '콜드 스타트 데이터'로 먼저 정렬합니다. R1-Zero 단계에서 나온 추론 사슬(CoT) 중 형식·언어 일관성에 문제 있는 것을 사람이 재작성해 깔끔하게 만들고, 이 (프롬프트→재작성) 쌍으로 SFT를 합니다. (규모는 다른 단계보다 몇 자릿수 작을 수 있음 — 수만 쌍 수준 추정)
  2. 추론 RL (+ 언어 일관성 보상): R1-Zero식 RL을 이어갑니다. 보상에 검증 가능한 정답 보상 + 형식 보상에 더해, 새로운 언어 일관성 보상(language consistency reward)을 추가합니다 — 출력 사슬에서 목표 언어 토큰의 비율을 보상으로 둬 언어 혼합을 막습니다.
  3. 대규모 SFT (거부 샘플링): 더 큰 규모로, 추론·비추론 데이터를 섞어 SFT합니다. 비추론 데이터는 V3용 데이터를 재활용(약 20만 쌍, 다양한 영역). 추론 데이터는 거부 샘플링(rejection sampling)으로 생성 — 지금까지 학습된 모델로 응답을 만들고, 심판으로 좋은 답만 남기고 나머지는 버려 고품질 데이터셋을 만듭니다. (추론:비추론 ≈ 3:1)
  4. 최종 정렬 RL: 마지막으로 추론·비추론을 섞어 RL. 추론은 같은 보상, 비추론은 도움이 됨(helpfulness)·무해함(harmlessness) 보상. 무해함은 출력 전체(추론 사슬 포함)에, 도움이 됨은 사용자에게 보이는 부분에 적용합니다.
용어 설명
cold start(콜드 스타트) 데이터
R1-Zero 사슬을 사람이 다듬어 만든 초기 SFT 데이터.
언어 일관성 보상(language consistency reward)
목표 언어 토큰 비율로 언어 혼합을 막는 보상.
거부 샘플링(rejection sampling)
생성한 답 중 좋은 것만 남기고 거르는 데이터 생성법.
도움이 됨/무해함(helpfulness/harmlessness)
최종 정렬 보상 차원.

한국어 번역

결과: 추론 벤치마크에서 비추론 모델과 추론 모델이 두 군집으로 갈리고, 추론 모델(R1 포함)이 훨씬 높습니다. R1은 추론을 표방하는 폐쇄형(closed source) 모델과 견줄 만했고, 그 수준을 (방법 공개와 함께) 재현했다는 점이 큰 사건이었습니다.

distillation(증류): 6,000억(600B) 파라미터 같은 거대 모델은 없고 작은 모델만 있는데 큰 추론 모델의 능력을 원하면? Lecture 2에서 본 증류를 떠올립니다(교사 모델의 확률 분포를 학생이 학습). 다만 여기선 추론용 SFT 쌍이 없으므로, 다른 방식의 증류를 씁니다.

  • 추론 사슬 생성: 교사 모델(R1)로 생각 토큰을 포함한 샘플 응답을 (오프라인으로) 생성합니다.
  • 학생 SFT: 그 생성물로 작은 모델을 SFT합니다 — 다음 토큰의 확률 분포를 맞추는 대신, 교사가 출력한 토큰 시퀀스 전체를 그대로 예측하게 학습합니다.

결과는 폐쇄형 소형 추론 모델(예: o1-mini)과 견줄 만했습니다. 왜 굳이 증류하나(작은 모델에 직접 RL을 하지)? — 작은 크기에서는 지식을 증류하는 것이 맨바닥에서 RL로 배우는 것보다 성능 면에서 더 효율적이기 때문입니다.

용어 설명
distillation(증류)
큰 교사 모델의 능력을 작은 학생 모델로 옮기는 것. (Lecture 2 섹션 5)
추론 증류 방식
교사로 추론 사슬을 생성 → 학생이 그 토큰 시퀀스를 SFT로 학습.
작은 모델엔 증류가 효율적
직접 RL보다 증류가 성능 대비 효율이 높음.

💡 현장에서 써먹기
  • R1이 방법을 공개해 폐쇄형 수준을 재현한 사건은 "오픈 모델의 빠른 추격"을 보여준다. 최고 수준 추론 능력이 공개 방법으로 재현 가능해지면서, 기관도 오픈 모델 기반으로 고성능 도구를 검토할 여지가 커졌다. 특정 상용 서비스에만 의존하지 않아도 되는 선택지가 늘었다는 의미다.
  • 증류는 "작고 싼 모델로 큰 모델 능력을 옮기는" 실용 경로다. 거대 추론 모델을 직접 운영하긴 비싸지만, 그 능력을 증류한 소형 모델은 저비용으로 쓸 만하다. 온디바이스·저예산 환경에서 추론형 소형 모델을 고를 때의 근거 개념이다(Lecture 2·4 증류와 연결).
  • 거부 샘플링·다단계 정렬은 "고품질 데이터를 자동으로 거르는" 발상을 준다. 모델로 많이 생성한 뒤 좋은 것만 남기는 방식은, 사람이 일일이 작성하지 않고도 양질의 데이터를 모으는 길이다. 업무 데이터 구축 시 'AI 생성 + 자동·사람 필터링' 조합을 참고할 수 있다.
