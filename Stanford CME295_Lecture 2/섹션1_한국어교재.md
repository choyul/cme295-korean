## 3. 본문

### 블록 1 — self-attention 복습

**영문 원문**
> (01:28) lecture one was all about introducing the concept of self attention. (...) each token is attending to all other token in the sequence through this mechanism of attention. So you have these notations of queries, keys and values. (...) the query is going to ask which other tokens are most similar to itself by comparing query and key and then (...) we will be taking the associated value. (...) soft max of query * (key) transpose over square root of dk * v. (...) this formula is highly optimized (...) big matrix multiplications that our hardware is very capable of doing.

**한국어 번역**
Lecture 1은 self-attention 개념을 소개하는 내용이었습니다. self-attention이란, 각 토큰이 어텐션 메커니즘을 통해 시퀀스 내 다른 모든 토큰에 주의를 기울이는(attend) 것입니다. 여기에 쿼리(query)·키(key)·값(value)이라는 표기가 등장합니다. 쿼리는 자신과 가장 비슷한 다른 토큰이 무엇인지를 쿼리와 키를 비교해 묻고, 그다음 그에 연결된 값을 가져옵니다.

self-attention은 다음 공식으로 표현됩니다:

**softmax(Q·Kᵀ / √dₖ) · V**

이 공식은 고도로 최적화돼 있습니다. 큰 행렬 곱셈으로 이뤄지는데, 오늘날 하드웨어(GPU)가 이런 연산을 매우 잘 처리합니다.

**용어 설명**
- **self-attention**: 각 토큰을 시퀀스 내 모든 토큰과의 관계로 표현하는 메커니즘.
- **쿼리·키·값(Q·K·V)**: 비교 주체 / 비교 대상 / 실제로 가져올 벡터.
- **softmax(QKᵀ/√dₖ)V**: self-attention 핵심 공식. √dₖ로 나눠 내적 크기를 정규화. (Lecture 1 섹션 5 참고)

### 블록 2 — 트랜스포머 구조와 멀티헤드 어텐션

**영문 원문**
> (02:57) the transformer is composed of two main components. So the encoder on the left side and the decoder on the right side and (...) was initially introduced in the context of machine translation. (...) this multi head attention layer is where the self attention mechanism happens. (...) (03:43) you can think of each head as an opportunity for the model to learn one way of projecting the input into being a query, a key or a value. (...) (07:30) we're going to have different projection matrices for each of them (...) each head is going to have its own projection and in parallel you're going to have that computation (...) each head is going to have one result (...) then concatenated and then projected once again with the output matrix.

**한국어 번역**
트랜스포머는 두 부분으로 구성됩니다 — 왼쪽의 인코더(encoder)와 오른쪽의 디코더(decoder)입니다. 처음에는 기계번역 맥락에서 도입됐습니다. 멀티헤드 어텐션 층(multi-head attention layer)이 self-attention이 일어나는 곳입니다.

각 헤드(head)는 모델이 입력을 쿼리·키·값으로 투영하는 '한 가지 방식'을 학습할 기회라고 볼 수 있습니다. 청중 질문("이 계산들이 서로 다른 MLP를 거치느냐")에 대한 답은 — 각 헤드마다 별도의 투영 행렬을 갖는다는 것입니다. 각 헤드가 자기만의 투영을 갖고 병렬로 계산되며, 헤드마다 하나의 결과를 내고, 이를 이어 붙인(concatenate) 뒤 출력 행렬(W_O)로 다시 한 번 투영합니다. 즉 고도로 병렬화돼 있고, 투영·행렬곱·softmax로 이뤄집니다.

**용어 설명**
- **인코더/디코더(encoder/decoder)**: 입력 처리 부분 / 출력 생성 부분.
- **멀티헤드 어텐션(multi-head attention)**: 어텐션을 여러 헤드로 병렬 수행해 다양한 투영을 학습.
- **헤드(head)**: 입력을 Q·K·V로 투영하는 한 벌의 행렬. 헤드마다 다른 방식 학습.
- **MLP(Multi-Layer Perceptron, 다층 퍼셉트론)**: 기본 신경망. 여기서는 헤드별 투영을 가리키는 청중 표현.

### 블록 3 — 어텐션 맵(attention map): 헤드 해석하기

**영문 원문**
> (04:54) we have this concept called attention map which (...) tries to represent the value of each of these query (dot) product query. (...) we take a look at (...) the query (...) (dot) product all other keys and we look at what other keys are leading to a high value (...) (05:47) you have these two words. So application and law which are highlighted as being with a high attention weight. (...) the token (eats) is referring to law (...) it is also referring to application. (...) (06:44) these heads may learn different ways of figuring out what words matters.

**한국어 번역**
어텐션 맵(attention map)이라는 개념이 있습니다. 어떤 토큰의 쿼리를 다른 모든 키와 내적했을 때, 어떤 키가 높은 값을 내는지를 시각화한 것입니다. 즉 어텐션 가중치(attention weight) = 그 토큰의 쿼리와 각 토큰의 키의 내적값을 봅니다.

「Attention Is All You Need」 논문의 예에서, 'eats'라는 토큰의 어텐션을 보면 'application'과 'law'라는 단어가 높은 가중치로 강조됩니다. 'eats'가 (문맥상) 'law'를 가리키고 'application'과도 연관되기 때문에, 이는 말이 됩니다. 모델이 이런 단어 연관을 학습한 것입니다.

저자들은 이 값들을 헤드별로 나눠 보여줬습니다. 예를 들어 한 헤드는 어떤 단어에 강한 강도를, 다른 헤드는 'law'에 매우 높은 강도를 보입니다. 즉 헤드들은 '어떤 단어가 중요한지'를 서로 다른 방식으로 학습합니다.

> 강사는 「Attention Is All You Need」 논문을 직접 읽어볼 것을 강력히 권했다. 몇 페이지 안 되지만 밀도 높은 논문이며, Lecture 1 내용을 바탕으로 읽으면 소화할 수 있다고 했다.

**용어 설명**
- **어텐션 맵(attention map)**: 한 토큰이 다른 토큰들에 얼마나 주의를 기울이는지(쿼리·키 내적값)를 시각화한 표.
- **어텐션 가중치(attention weight)**: 쿼리와 키의 내적값. 높을수록 두 토큰이 강하게 연결됨.

## 4. 핵심 용어집

| 영문 | 한국어 | 발음 | 뜻 |
|---|---|---|---|
| self-attention | 셀프 어텐션 | 셀프 어텐션 | 토큰을 모든 토큰 관계로 표현 |
| query / key / value | 쿼리/키/값 | 큐·케이·브이 | 비교 주체 / 대상 / 가져올 벡터 |
| multi-head attention | 멀티헤드 어텐션 | 멀티헤드 | 여러 헤드로 병렬 어텐션 |
| head | 헤드 | 헤드 | Q·K·V 투영 행렬 한 벌 |
| projection matrix | 투영 행렬 | 프로젝션 매트릭스 | 입력을 Q·K·V로 변환하는 행렬 |
| attention map | 어텐션 맵 | 어텐션 맵 | 토큰 간 주의 정도 시각화 |
| attention weight | 어텐션 가중치 | 어텐션 웨이트 | 쿼리·키 내적값 |
| encoder / decoder | 인코더/디코더 | 인코더/디코더 | 입력 처리 / 출력 생성 |

## 부록. 실무 적용 포인트 (NLP·LLM 기술 내용 한정)

- **어텐션 맵은 "AI가 왜 그렇게 답했는지"를 들여다보는 단서다.** 모델이 특정 단어에 어떻게 주의를 기울였는지 시각화할 수 있다는 것은, AI 판단의 근거를 부분적으로 해석할 수 있다는 의미다. 다만 이는 연구·디버깅 수준의 도구이고, 완전한 설명을 주지는 않는다는 점은 유의해야 한다.
- **self-attention이 행렬 연산이라 GPU에 최적화돼 있다는 점은 비용·속도의 근거다.** 트랜스포머가 빠르게 확장될 수 있었던 이유가 하드웨어 친화적 구조라는 데 있다. AI 서비스의 처리 속도·비용이 결국 GPU 연산량에 좌우된다는 점을 이해하는 토대가 된다.
