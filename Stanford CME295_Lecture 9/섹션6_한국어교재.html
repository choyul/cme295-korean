1. 강의 개요

  • 모달리티 간 상호 영향(디퓨전·트랜스포머·입력·트릭의 교차 차용)과, 트랜스포머 연구가 여전히 활발하다는 점을 본다.
  • 진행 중인 연구 — 최적화기(Muon)·정규화·활성함수·데이터(모델 붕괴)·하드웨어(아날로그) — 와 미래 활용·과제를 정리한다.
  • 최신 동향을 따라가는 자료와 강사들의 맺음말로 마무리한다.

2. 학습 목표

  1. 모달리티 간 차용(디퓨전·ViT·DeepSeek-OCR·2D RoPE)의 예를 설명할 수 있다.
  2. 트랜스포머의 여러 설계가 여전히 연구 중임(최적화기·정규화·데이터·하드웨어)을 안다.
  3. 미래 활용·과제와, 최신 동향을 따라가는 자료를 안다.

한국어 번역

이미지와 텍스트가 서로 영향을 주고받습니다.

  • 아키텍처: 디퓨전(이미지 출신)이 텍스트로 와 속도를 높였고(섹션 5), 반대로 이미지 디퓨전이 합성곱(CNN) 대신 트랜스포머를 써 더 좋아졌습니다(디퓨전 트랜스포머).
  • 입력: DeepSeek-OCR — 이름과 달리 OCR 성능 자랑이 아니라, '아주 적은 비전 토큰'으로 텍스트 토큰을 표현하는 함수를 학습할 수 있음을 보였습니다. 이미지 패치 토큰의 표현력이 강하다는 것 — "토크나이저가 최선이 아니다"라는 논거(이모지 등은 텍스트로는 많은 토큰이 필요하지만 패치는 의미를 바로 담음)와 연결됩니다.
  • 트릭: RoPE(텍스트의 상대 위치)를 이미지·멀티모달에서 2D로 재구성해 적용 — 2D 격자에서 위치를 부여해 텍스트·이미지 토큰의 상대 위치 계산이 여전히 의미 있게 만듭니다.
용어 설명

DeepSeek-OCR
적은 비전 토큰으로 텍스트를 표현하는 표현력을 보인 연구.
2D RoPE
RoPE를 2차원으로 확장해 이미지·멀티모달에 적용.

한국어 번역

트랜스포머의 세부 설계는 여전히 연구 중이며, 각 결정이 계속 갱신됩니다.

  • 최적화기(optimizer): 오래 표준이던 Adam이 새 논문으로 도전받습니다 — Kimi K2 논문이 Muon(과 최신판 MuonClip)이라는 새 최적화기를 제시, 차기 표준 후보로 거론됩니다.
  • 정규화: 위치(post-norm→pre-norm)뿐 아니라 종류도 바뀜 — 원논문의 layer norm 대신 요즘은 파라미터가 적은 RMSNorm 등.
  • 어텐션 변형: GQA 등 고정 설계가 아니라 논문마다 다르고, 층마다 다른 어텐션을 쓰기도.
  • 활성함수: 전통적 ReLU에서 GELU(가우시안 오차 선형 유닛) 같은 'ReLU 유사' 함수로 이동, 여전히 새 함수가 나옴.
  • 그 외 MoE 여부·층 수·FFN 크기 등 하이퍼파라미터도 논쟁 중. 즉 아키텍처 자체가 최선인지도 열린 문제.
용어 설명
Adam → Muon/MuonClip
표준 최적화기에 대한 새 도전(Kimi K2).
RMSNorm / GELU
최근 자주 쓰는 정규화 / 활성함수.
설계 미확정
최적화기·정규화·활성함수·구조 모두 진행 중인 연구.

한국어 번역

데이터: 초기 LLM은 인터넷을 긁으면 사람이 쓴 고품질 데이터를 얻을 수 있었습니다. 지금은 검색 결과의 80%가 LLM 생성일 정도로 바뀌었습니다. 그래서 데이터 큐레이션이 중요해졌고(단순 스크래핑→관심 데이터 선별), 사전학습-중간학습(mid-training, 더 고품질)-파인튜닝으로 단계가 늘었습니다. LLM 생성 데이터로 학습하면 모델 붕괴(model collapse) — 분포가 변해 학습 의미가 줄어드는 현상 — 가 보고됐고, 데이터 작업의 필요성을 강조합니다.

비용·소형화: 모든 쓸 일을 푸는 단계가 오면, 다음은 비용 효율의 Pareto 프런티어로 — 점점 작은 모델(SLM, Small Language Model)이 부상합니다. LLM 제공자가 최고 요금제에서도 손해 본다는 말은, 추론 시 연산을 더 영리하게 써야 함을 보여줍니다.

하드웨어: GPU는 행렬 곱에 강하지만, 트랜스포머엔 그것만이 아닌 특수 연산(QKᵀ 등 비싼 부분)이 있습니다(FlashAttention이 메모리 이동을 줄이려 재계산까지 한 이유). 그래서 더 맞춤한 하드웨어 연구가 나옵니다 — 한 논문은 연산을 아날로그 신호의 부수효과로 하드웨어에 새깁니다(키르히호프 법칙 같은 물리 성질로 입력 펄스를 더해 결과를 읽음). 시뮬레이션 결과 지연·에너지 모두 크게 개선됐습니다(연산을 직접 안 하고 부수효과로 얻으므로).

용어 설명
데이터 큐레이션 / 중간학습(mid-training)
데이터를 선별 / 사전학습 후 고품질 단계.
모델 붕괴(model collapse)
LLM 생성 데이터로 학습 시 분포가 망가지는 현상.
SLM(Small Language Model)
비용 효율을 노린 소형 모델.
아날로그 하드웨어
연산을 물리 신호의 부수효과로 수행하는 새 하드웨어 연구.

한국어 번역

오늘의 활용: 코딩 보조(자연어→코드, 에이전트 모드), 범용 비서(사실 조회·웹 탐색), 창의 작업(마케팅 등 백지에서 초안), 학습 보조(개념 브레인스토밍 — 강의 중 학생들이 ChatGPT로 개념을 찾아보는 것은 학습에 좋음).

다가오는 것: 에이전트 워크플로의 대중화(코딩 없이 자연어로 유용한 것을 만듦), AI의 웹 브라우징(예: ChatGPT Atlas, 2025년 10월 — 단 보안 과제: 악성 프롬프트 주입·데이터 유출. 미래엔 'AI 브라우징 안전 인증서' 같은 게 나올 수도), OS 수준 보조 등.

남은 과제: 에이전트는 단계가 늘수록 실패 확률↑(안정화가 관건). AI 고객센터가 진짜 유용한가는 좋은 시험대(사람은 시스템 프롬프트에 없는 것도 분별하는 등 가치 차원이 많음). 현재 아키텍처의 근본 과제 — ① 학습 후 가중치가 안 변함(RAG·도구로 우회하지만, 지속 학습은 열린 문제), ② '환각'(LLM은 사실 대응이 아니라 다음 토큰 예측으로 학습됐으니 환각은 어느 정도 설계상 본질), ③ 개인화·해석가능성·안전 등.

용어 설명
대중화(democratization)
코딩 없이 자연어로 누구나 도구를 만듦.
지속 학습(continual learning)
배포 후에도 계속 배우는 것. 열린 과제.
환각(hallucination)
사실과 다른 생성. 다음 토큰 예측이라는 설계상 본질적 측면.

부록. 실무 적용 포인트 (NLP·LLM 기술 내용 한정)

💡 현장에서 써먹기
  • "설계가 아직 확정이 아니다"는 점은 "AI는 빠르게 변한다"는 실무 전제다. 최적화기·정규화·구조가 계속 바뀌므로, 특정 모델·도구에 고착하기보다 동향을 주기적으로 점검하는 자세가 필요하다. 스터디 가이드·arXiv·해설 영상 등이 따라가는 통로다.
  • 모델 붕괴·데이터 큐레이션은 "AI 시대 데이터 품질의 중요성"을 일깨운다. 인터넷이 AI 생성물로 채워질수록 고품질·사람 검증 데이터의 가치가 커진다. 기관 고유의 정제된 데이터(검증된 내부 자료)가 점점 더 귀한 자산이 된다는 의미다.
  • 환각·지속 학습·고객센터 사례는 "AI의 한계를 알고 쓰라"는 결론이다. 환각은 설계상 본질이고, 모델은 배포 후 스스로 갱신되지 않으며, 사람의 분별을 완전히 대체하긴 어렵다. AI를 보조로 두고 사람이 검증·판단하는 구조가 — 특히 대민·사실성 업무에서 — 여전히 옳다.
