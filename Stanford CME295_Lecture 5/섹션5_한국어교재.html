섹션 5. RL 정렬 — 보상 해킹·KL 발산·PPO

📄원문 출처: Stanford CME295, Autumn 2025, Lecture 5, 타임스탬프 46:03~1:19:00

1. 강의 개요

  • 보상 모델로 LLM을 정렬하는 RL 단계의 큰 그림(완성 응답 생성 → 보상 → 튜닝)과, 기본 모델에서 너무 벗어나면 안 되는 이유를 다룬다.
  • 보상 해킹(reward hacking)·KL 발산·어드밴티지(advantage)·가치 함수(value function) 개념을 본다.
  • 대표 알고리즘 PPO(PPO-clip, KL penalty)의 직관과, RL 기반 정렬의 도전과제·on-policy 개념을 설명한다.

2. 학습 목표

  1. RL 정렬에서 "보상은 키우되 기본 모델에서 너무 벗어나지 않는다"는 두 목표와 그 이유(보상 해킹·망각·불안정)를 설명할 수 있다.
  2. KL 발산·어드밴티지·가치 함수가 각각 무엇인지 안다.
  3. PPO-clip이 정책 갱신을 제한하는 직관과, RL 정렬의 도전과제·on-policy 개념을 이해한다.

3. 본문

블록 1RL 정렬의 큰 그림과 보상 해킹

한국어 번역

RL 정렬의 흐름은 이렇습니다. 프롬프트를 입력하면 LLM이 완성 응답(completion, =롤아웃rollout)을 생성합니다. 그 응답이 보상 모델로 들어가 점수(예: −2)를 받고, 이 보상으로 LLM을 튜닝합니다. 중요한 점: 보상 모델은 동결(frozen)돼 있습니다 — 우리가 학습하는 건 LLM(정책)입니다.

목표는 두 가지: 보상을 키우되, 기본 모델(base model)에서 너무 벗어나지 않기. 왜 벗어나면 안 될까요?

  1. 망각(catastrophic forgetting): 사전학습·SFT로 쌓은 지식을 잃지 않으려고.
  2. 보상 해킹(reward hacking): 보상 모델이 불완전하기 때문. 보상만 과하게 좇으면, 보상은 최대화되지만 진짜 목표는 안 채워집니다. 비유 — 강의의 목표가 '유익함'인데 보상을 '박수 소리 크기'로 두면, 농담만 해서 박수는 커지지만 강의가 유익해지진 않습니다.
  3. 학습 불안정: 너무 큰 갱신은 학습을 불안정하게 만듦.
용어 설명
완성 응답(completion)/롤아웃(rollout)
모델이 생성한 전체 응답.
동결(frozen) 보상 모델
정렬 단계에서 보상 모델은 학습하지 않음.
보상 해킹(reward hacking)
불완전한 보상을 과하게 좇아 진짜 목표를 놓치는 현상.
망각(catastrophic forgetting)
새 학습으로 기존 지식을 잃는 것.

블록 2KL 발산

▸ 영문 원문 보기

54:03 PO (...) proximal policy (optimization) (...) we do not want our model to deviate too much (...) 54:36 a reward (...) to maximize and (...) measuring how far the distribution of the policy (...) is to the reference model. (...) 55:38 the K(L) divergence (...) some measure of how far two probability distributions are (...) sum of PI log of PI over QI. (...) 56:42 it's positive (...) Jensen's inequality (...) equal to zero if and only if P and Q are equal.

한국어 번역

이 두 목표를 담은 손실에는 두 부분이 있습니다 — 보상 모델 점수(최대화)와, 학습 중인 정책 분포가 기준 모델(reference, 여기선 SFT 모델)에서 얼마나 떨어졌는지를 재는 항. 후자에 KL 발산(KL divergence)을 씁니다.

KL 발산은 두 확률 분포 P, Q가 얼마나 떨어졌는지 재는 척도입니다(거리는 아님). 공식은 Σ Pᵢ log(Pᵢ/Qᵢ)입니다. 손실을 최소화한다는 건 두 분포가 너무 벌어지지 않게 한다는 뜻입니다. KL 발산은 항상 0 이상이며(Jensen 부등식으로 증명), P=Q일 때만 0입니다.

용어 설명
KL 발산(KL divergence)
두 확률 분포의 차이를 재는 척도(거리는 아님). 항상 ≥0, 같을 때 0.
기준 모델(reference model)
비교 대상. 보통 SFT 모델.

블록 3어드밴티지와 가치 함수

▸ 영문 원문 보기

57:47 we don't want to maximize rewards. We actually want to maximize a quantity called advantage (...) how much better is your output compared to what you would expect (...) more stable. (...) 58:47 the value function (...) 59:17 at the token level (...) takes in the prompt along with the partial generation (...) predicts the reward if you were to (...) continue (...) following the policy. (...) 1:00:51 a (...) value head (...) regression problem (...) trained jointly. (...) 1:02:30 reward minus baseline (...) reduces the variance.

한국어 번역

사실 RL에서는 보상 자체가 아니라 어드밴티지(advantage)를 최대화합니다. 어드밴티지란 '내 출력이 기대치보다 얼마나 더 나은지'입니다. 보상에서 기준선(baseline, 평균적 기대 보상)을 뺀 값으로, 추정의 분산(variance)을 줄여 학습을 안정·가속합니다.

이 기대치를 추정하는 것이 가치 함수(value function)입니다. 보상은 완성 응답 단위였지만, 가치 함수는 토큰 단위 추정입니다 — (프롬프트 + 부분 생성)을 받아, 그 정책대로 계속 생성하면 받을 보상을 예측합니다. 이를 위해 LLM에 가치 헤드(value head)를 붙이는데, 이건 분류가 아니라 회귀(regression) 문제이며, 정책과 함께(jointly) 학습됩니다.

⚠️ 참고

어드밴티지의 정확한 공식(일반화 어드밴티지 추정, GAE)은 이 수업 범위 밖이라 다루지 않습니다. 관심 있으면 GAE 논문 참고.

용어 설명
어드밴티지(advantage)
출력이 기대치(기준선)보다 얼마나 나은지. = 보상 − 기준선.
가치 함수(value function)
(프롬프트+부분 생성)으로 앞으로 받을 보상을 토큰 단위로 추정.
가치 헤드(value head)
가치 함수를 내는 회귀용 출력 층. 정책과 함께 학습.
분산 감소(variance reduction)
기준선을 빼 추정 변동을 줄여 학습 안정.

블록 4PPO: PPO-clip과 KL penalty

▸ 영문 원문 보기

(...) 1:12:39 KL penalty (...) the ratio times the advantage minus the K(L) divergence (...) nowadays, people use the reference. (...) 1:13:47 they (...) mix the two.

한국어 번역

대표 알고리즘은 PPO(Proximal Policy Optimization, 근접 정책 최적화)입니다. '근접(proximal)'은 모델이 한 번에 너무 많이 변하지 않게 한다는 뜻입니다. 두 변형이 있습니다.

① PPO-clip: 한 번의 갱신이 너무 커지지 않게 막습니다. 손실에 비율(ratio) r_θ가 나오는데, 이건 보상이 아니라 '현재 정책과 직전 정책의 확률 비'입니다(직전 = SFT가 아니라 RL 단계의 이전 반복). 직관:

  • 어드밴티지가 양수면(좋은 출력) → 그 출력의 확률을 높이고 싶음(r↑). 단 너무 높이지 않게 위쪽을 자름(clip).
  • 어드밴티지가 음수면(나쁜 출력) → 그 출력의 확률을 낮추고 싶음(r↓). 단 너무 낮추지 않게 아래쪽을 자름.

이렇게 '강화하되 과하지 않게' 합니다.

② KL penalty: 비율 × 어드밴티지 − (정책 간 KL 발산) 형태. 원래(2017 논문)는 직전 반복과의 KL이었지만, 요즘 LLM에서는 기준(reference) 모델과의 KL을 씁니다. 실무에서는 두 변형(clip + KL)을 섞어 쓰기도 합니다.

⚠️ 참고

비율 r_θ는 입력에 대한 토큰 확률(출력 분포)로 계산합니다.

용어 설명
PPO(근접 정책 최적화)
정책이 한 번에 너무 변하지 않게 제한하는 대표 RL 알고리즘.
비율 r_θ
현재 정책 ÷ 직전 정책의 확률 비(보상 아님).
클리핑(clipping)
갱신 비율을 일정 범위로 잘라 과도한 변화 방지.
PPO-clip / KL penalty
비율을 자르는 변형 / KL로 벌점 주는 변형.

한국어 번역

RL 기반 정렬의 도전과제들:

  1. 두 단계 의존성: 보상 모델 학습 → 정책 학습 순인데, 나중에 보상 모델 문제를 발견하면 전부 다시 해야 합니다. 학습 레시피가 복잡합니다.
  2. 하이퍼파라미터 많음: KL의 β, PPO-clip의 ε, GAE의 하이퍼파라미터 등. 재학습이 필요하면 다 다시 맞춰야 합니다.
  3. 불안정성: 반복 폭을 제한해도 통제가 늘 쉽지 않습니다.
  4. 모니터링 어려움: 보통 평균 보상으로 학습을 지켜보지만, 사전학습·SFT의 교차 엔트로피만큼 명확한 지표는 아닙니다.
  5. 탐색(exploration) 필요: 매번 너무 비슷한 응답만 생성하면 가능한 응답 공간을 탐색하지 못합니다. 다양성을 강제해야 합니다.

on-policy vs off-policy: RL 정렬은 on-policy 학습입니다 — 매 단계 모델이 '현재 정책'으로 출력을 생성하고, 그 출력의 좋고 나쁨으로 모델을 갱신합니다. SFT는 모델이 생성하지 않은 데이터를 쓰므로 off-policy에 가깝습니다. 즉 on-policy는 학습 중인 모델 자신의 생성에 기반합니다.

용어 설명
하이퍼파라미터(hyperparameter)
β·ε 등 사람이 정하는 값. RL엔 많아 튜닝이 부담.
탐색(exploration)
다양한 응답을 시도해 더 나은 것을 찾는 것. RL에 필수.
on-policy / off-policy
학습 중 모델 자신의 생성으로 학습 / 외부 데이터로 학습.

부록. 실무 적용 포인트 (NLP·LLM 기술 내용 한정)

💡 현장에서 써먹기
  • 보상 해킹은 "지표를 잘못 정하면 AI가 엉뚱하게 최적화한다"는 경고다. 박수 소리 비유처럼, 측정하기 쉬운 대리 지표를 좇으면 진짜 목표를 놓친다. AI 도입 성과를 측정할 때, 측정하기 쉬운 숫자(처리 건수 등)가 진짜 목표(주민 만족 등)와 어긋나지 않는지 늘 점검해야 한다.
  • "기본 모델에서 너무 벗어나지 말라"는 정렬 원칙은 '망각'의 실재를 보여준다. 모델을 한 방향으로 과하게 조정하면 기존 능력을 잃는다. 업무용 미세조정을 할 때도 특정 과제만 과하게 학습시키면 일반 능력이 퇴화할 수 있다는 점을 유의해야 한다.
  • RL 정렬의 복잡성·불안정성은 "정렬은 기관이 직접 하기 어렵다"를 시사한다. 두 단계 의존성·많은 하이퍼파라미터·불안정성 때문에 RLHF는 고난도다. 그래서 다음 섹션의 더 간단한 대안(DPO)이 나왔고, 실무에서는 잘 정렬된 기성 모델을 쓰는 게 현실적이다.
