섹션 3. 강화학습 기초와 RLHF 개요

📄원문 출처: Stanford CME295, Autumn 2025, Lecture 5, 타임스탬프 17:52~28:33

1. 강의 개요

  • 선호로 모델을 정렬하는 대표 방법 RLHF의 토대인 강화학습(RL) 기초 개념(에이전트·상태·행동·정책·보상)을 다룬다.
  • 이 개념들을 LLM에 어떻게 대응시키는지(LLM=에이전트, 입력=상태, 다음 토큰=행동, 출력 분포=정책)를 본다.
  • RLHF가 두 단계(보상 모델 학습 → RL 정렬)로 이뤄지며, '사람 피드백'이 어디에 들어가는지(RLHF vs RLAIF) 설명한다.

2. 학습 목표

  1. RL의 기본 요소(에이전트·상태·행동·정책·보상)를 설명할 수 있다.
  2. 이 요소들이 LLM에 어떻게 대응되는지(정책 = 출력 확률 분포 등) 안다.
  3. RLHF의 두 단계와, 보상 신호가 SFT보다 희소(sparse)한 이유를 이해한다.

한국어 번역

RLHF는 강화학습(RL, Reinforcement Learning)에 기반합니다. RL의 기본 그림은 이렇습니다 — 에이전트(agent)가 환경(environment)과 상호작용합니다.

  • 에이전트는 어떤 시점 t에 상태(state, sₜ)에 있습니다.
  • 그 상태에서 행동(action, aₜ)을 취하는데, 정책(policy)에 따라 합니다. 정책은 보통 π_θ(a|s)로 표기하며, '상태가 주어졌을 때 그 행동을 할 확률'입니다.
  • 행동을 하면 보상(reward)을 받습니다(좋은 보상일 수도, 나쁜 보상일 수도).
용어 설명
강화학습(RL)
에이전트가 행동하고 보상을 받아 정책을 개선하는 학습 방식.
에이전트/환경(agent/environment)
행동 주체 / 그가 상호작용하는 세계.
상태/행동(state/action)
지금 처한 상황 / 취하는 선택.
정책(policy, π_θ)
상태가 주어졌을 때 행동을 고를 확률.
보상(reward)
행동의 결과로 받는 점수.

한국어 번역

이 개념들을 LLM에 대응시켜 봅니다.

  • 에이전트 = LLM.
  • 상태 = 지금까지의 입력(모델이 본 토큰들).
  • 행동 = 다음 토큰 예측(어휘 집합 중 하나를 고름). 즉 환경은 어휘의 토큰 집합으로 볼 수 있습니다.
  • 정책 = LLM의 출력 확률 분포. 순전파로 얻는 다음 토큰 확률이 곧 정책입니다.

여기에 하나를 더합니다 — 선호 데이터로 "어느 출력이 더 나은지"를 알므로, 이를 보상(reward)으로 씁니다. LLM이 입력을 받아 다음 토큰을 고르고(정책 사용), 생성한 출력이 보상을 받아 그 보상이 에이전트(LLM) 튜닝에 되먹임됩니다.

용어 설명
에이전트=LLM, 상태=입력, 행동=다음 토큰, 정책=출력 확률 분포
RL↔LLM 대응.
보상=선호 신호
어느 출력이 나은지를 보상으로 활용.

한국어 번역

보상은 SFT보다 신호가 희소(sparse)합니다. SFT는 늘 부분 입력을 받아 다음 토큰 생성을 가르치므로 토큰마다 신호가 있지만, RL에서는 한 완성 응답(completion)당 대략 하나의 보상 신호만 받습니다. 그래서 RLHF는 희소한 신호 기반 접근으로 여겨집니다. (보상은 토큰별이 아니라 전체 응답에 대해 줍니다.)

RLHF(Reinforcement Learning from Human Feedback, 사람 피드백 기반 강화학습)는 두 단계입니다.

  1. 보상 모델 학습: 좋은 출력과 나쁜 출력을 구분하는 법을 배웁니다. 입력은 (프롬프트+응답)의 결합, 출력은 점수입니다. 모은 선호 쌍이 여기 쓰입니다.
  2. RL 정렬: 그 보상을 써서 모델을 선호에 맞춥니다. 입력은 프롬프트, 목표는 보상에 더 부합하는 ŷ 생성입니다.

'사람 피드백(human feedback)'이란 보상 모델을 학습시키는 라벨이 사람 평가라는 뜻입니다. 라벨이 사람 선호면 RLHF, 비사람(다른 AI) 선호면 RLAIF(RL from AI Feedback)라 부릅니다.

용어 설명
희소 보상(sparse reward)
완성 응답당 신호 하나. SFT(토큰마다 신호)보다 적음.
완성 응답(completion)
모델이 생성한 전체 응답.
RLHF
사람 피드백 기반 강화학습. ① 보상 모델 학습 → ② RL 정렬.
RLAIF
사람 대신 AI 피드백으로 보상 모델을 학습하는 변형.

부록. 실무 적용 포인트 (NLP·LLM 기술 내용 한정)

💡 현장에서 써먹기
  • '정책 = 출력 확률 분포'라는 대응은 LLM을 RL 관점에서 이해하는 핵심이다. 모델 정렬이 '확률 분포(정책)를 선호에 맞게 조금씩 옮기는 일'임을 알면, 정렬된 모델이 왜 특정 어조·태도를 일관되게 보이는지 납득된다.
  • 희소 보상은 "정렬 학습이 왜 까다로운가"의 한 이유다. 응답 하나에 신호 하나뿐이라 학습이 불안정하고 어렵다. 정렬은 비싸고 섬세한 과정이며, 그래서 기관이 직접 RLHF를 하기보다 잘 정렬된 기성 모델을 쓰는 게 합리적이라는 판단으로 이어진다.
