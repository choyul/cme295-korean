## 섹션 5. 파인튜닝(SFT)과 instruction tuning

> 원문 출처: Stanford CME295, Autumn 2025, Lecture 4, 타임스탬프 (1:02:30)~(1:25:24)

---

## 1. 강의 개요

- 사전학습만 한 모델은 '다음 토큰 예측기'일 뿐 비서가 아니라는 점을, 곰인형 세탁 질문 예로 보인다.
- 사전학습 모델을 도움이 되게 만드는 지도 파인튜닝(SFT)과, 그 핵심인 instruction tuning을 다룬다.
- SFT 데이터의 구성(과제별 입력-출력 쌍, 안전 데이터)과 규모, 그리고 도전과제(데이터 품질·분포·일반화)를 본다.

---

## 2. 학습 목표

1. 사전학습 모델이 왜 곧바로 '비서'가 아닌지, SFT가 무엇을 바꾸는지 설명할 수 있다.
2. SFT에서 입력에는 손실을 두지 않고 출력부터 다음 토큰을 예측한다는 점, instruction tuning의 의미를 안다.
3. SFT 데이터의 종류(과제별·안전)와 규모(사전학습보다 훨씬 작음), 도전과제를 이해한다.

---

## 3. 본문

### 블록 1 — 사전학습 모델은 아직 비서가 아니다

**영문 원문**
> (1:03:41) we have thoroughly loved our teddy bear (...) now it has become a bit dirty (...) you might want to ask your favorite LLM (...) if you can put it in the washer (...) (1:04:23) it has been trained on next token prediction not being an assistant (...) it will try to mimic (...) potential likely next words. (...) (1:05:19) are you happy with it? No. (...) this is why we're going to see what we can do (...) to make it helpful (...) this stage is called fine-tuning.

**한국어 번역**
예를 들어 봅시다. 아끼던 곰인형이 더러워져서, LLM에게 "세탁기에 넣어도 되냐"고 묻습니다. 사전학습만 한 모델은 어떻게 답할까요? 이 모델은 '비서가 되도록'이 아니라 '다음 토큰 예측'으로 학습됐습니다. 그래서 질문에 답하는 대신, 그럴듯한 다음 단어 패턴을 흉내 냅니다 — 예컨대 곰인형 소재에 관한 문장(학습 데이터에 그런 텍스트가 있었으니)을 이어 쓰거나, 또 다른 질문을 던지는 식입니다.

이 결과에 만족하나요? 아니죠. 그래서 모델을 '도움이 되게' 만드는 단계가 필요합니다. 이를 파인튜닝(fine-tuning)이라 합니다.

**용어 설명**
- **사전학습 모델의 한계**: 다음 토큰 예측기일 뿐, 질문에 답하는 비서가 아님.
- **파인튜닝(fine-tuning)**: 사전학습 모델을 도움이 되게 조정하는 단계.

### 블록 2 — 지도 파인튜닝(SFT)과 손실 위치

**영문 원문**
> (1:05:52) model fine-tuning is commonly known as SFT (...) supervised fine-tuning. So the supervised part suggests that we need some labels (...) pairs of inputs and outputs (...) (1:06:57) the objective function even though it's the same will differ a bit (...) (1:07:26) washing my teddy bear is actually an input (...) I don't want the model to parrot what I say (...) the input is not a location where you would predict the next token. You would not do teacher forcing on it, but rather start from this input and then predict the next token onwards. (...) (1:08:28) we don't put a loss over the input.

**한국어 번역**
파인튜닝은 흔히 SFT(Supervised Fine-Tuning, 지도 파인튜닝)라고 합니다. '지도(supervised)'란 라벨이 필요하다는 뜻으로, 입력-출력 쌍(pairs)을 모델에 줘서 학습시킵니다. '파인튜닝'은 이미 학습된 가중치를 다듬는다는 뜻 — 사전학습 가중치에서 출발해 추가 데이터로 더 학습합니다.

목적함수는 (다음 토큰 예측으로) 같지만 한 가지가 다릅니다. 사전학습에서는 BOS부터 모든 데이터에 대해 다음 토큰을 예측합니다. 하지만 SFT에서는 — 예컨대 "곰인형 세탁" 부분은 내가 모델에 주는 입력(input)이라 고정돼 있습니다. 모델이 내 말을 따라 외치길(parrot) 원하는 게 아니라, 그 입력에 도움이 되게 답하길 원합니다. 그래서 입력 부분에는 손실(loss)을 두지 않습니다(교사 강요를 하지 않음). 입력 다음부터 토큰을 예측하고, 그 부분부터 손실을 계산해 최적의 다음 토큰 분포를 학습시킵니다.

**용어 설명**
- **SFT(Supervised Fine-Tuning, 지도 파인튜닝)**: 입력-출력 쌍(라벨)으로 사전학습 모델을 다듬는 학습.
- **입력에 손실 없음**: 입력 부분은 예측 대상이 아니라 조건. 출력부터 손실 계산.
- **parrot(앵무새처럼 따라함)**: 입력을 그대로 반복하는 것. SFT가 막으려는 것.

### 블록 3 — instruction tuning과 데이터

**영문 원문**
> (1:09:00) this transition from (...) a good representation of language to a useful assistance is a subcategory of SFT called instruction (...) tuning. (...) we want the model to answer instructions. (...) (1:10:03) data that presents to the model how it can most helpfully respond to instructions (...) story writing (...) poem creation, list generation, explanation (...) (1:12:09) you can use these already trained LLMs to generate such data (...) (1:13:11) safety (...) helpful but also harmless (...) reject some user prompts.

**한국어 번역**
사전학습 모델(언어를 잘 표현)을 '도움이 되는 비서'로 바꾸는 것은 SFT의 한 갈래인 instruction tuning(지시 튜닝)입니다. 모델이 지시(instruction)에 답하길 원하는 것입니다.

데이터는 사전학습과 다릅니다. 사전학습은 인터넷 전체(위키피디아 등)였지만, instruction tuning은 '지시에 어떻게 가장 도움이 되게 답하는지'를 보여주는 데이터를 씁니다. 예: 이야기 쓰기, 시 짓기, 목록 생성, 설명 등 — 각각 입력(지시)과 정답(ground truth) 출력이 짝지어져 있습니다. 입력을 주고 출력 예측을 학습시킵니다.

데이터 출처: 원래는 사람이 직접 작성(전문 언어학자가 유창하고 도움이 되는 답을 작성)했지만, 요즘은 이미 성능 좋은 LLM으로 이런 데이터를 생성한 뒤 사람이나 다른 LLM이 품질을 검토하는 식으로 빠르게 만듭니다.

안전(safety)도 데이터 혼합에 포함됩니다. 모델이 도움이 되면서도(helpful) 해롭지 않게(harmless) 만들기 위해, 사전학습 때 본 유해 콘텐츠를 따라하지 않도록, 유해한 요청은 거부(reject)하도록 하는 데이터를 넣습니다. ("죄송하지만 답할 수 없다"를 정규식으로 처리하면 확장성이 없으니, 이 성질을 모델에 내장) 또 단정적 표현을 누그러뜨리는 헤징(hedging) 같은 행동도 데이터로 학습시킵니다.

**용어 설명**
- **instruction tuning(지시 튜닝)**: 모델이 지시에 도움이 되게 답하도록 만드는 SFT의 한 갈래.
- **정답(ground truth)**: 학습에 쓰는 모범 출력.
- **안전(safety) 데이터**: 유해 요청 거부 등 '도움 되면서 해롭지 않게' 만드는 데이터.
- **헤징(hedging)**: 단정 대신 신중하게 표현하도록 누그러뜨리는 것.

### 블록 4 — SFT의 규모와 instruction tuning 효과

**영문 원문**
> (1:17:54) GPT3 (...) about 13k (examples) (...) 10 million for (Llama) 3 (...) each example is about a thousand token (...) the size of the data sets used for SFT is several orders of magnitude lower than (...) pre-training. (...) (1:18:26) pre-training is a lot of data (...) SFT is (...) aligning the goal of the model to being suited for your tasks. (...) (1:18:59) (after instruction tuning) yes, you can put (...) the teddy bear in the washer except that you shouldn't (...) you should hand wash it.

**한국어 번역**
규모 감각: SFT 데이터는 토큰 수가 아니라 예시 수로 표기되곤 합니다. GPT-3는 약 1.3만(13k) 예시, Llama 3는 약 1,000만(10 million) 예시입니다. 예시 하나를 약 1,000토큰으로 잡아 곱해도, SFT 데이터셋은 사전학습보다 몇 자릿수(orders of magnitude) 작습니다.

사고 틀: 사전학습은 대량 데이터로 언어 일반을 배우는 것, SFT는 모델의 목표를 우리 과제에 맞게 정렬(align)하는 것입니다. 그래서 SFT는 매우 고품질의, 훨씬 적은 양의 데이터를 씁니다.

instruction tuning 후 같은 질문을 다시 하면 — "네, 세탁기에 넣을 수 있지만, 넣지 않는 게 좋고 손세탁을 권합니다"처럼, 사용자에게 도움이 되게 실제로 답합니다.

**용어 설명**
- **SFT 데이터 규모**: 예시 수로 표기(GPT-3 ~1.3만, Llama 3 ~1,000만). 사전학습보다 몇 자릿수 작음.
- **정렬(align)**: 모델의 목표·행동을 원하는 과제에 맞추는 것.

### 블록 5 — SFT의 도전과제: 데이터 품질·분포·일반화

**영문 원문**
> (1:20:04) we need high quality data and (...) often times human involved in the loop (...) very expensive in time and resources. (...) (1:21:06) the distribution of your SFT data set and how it would align with actual inference distribution (...) (1:21:36) a story that is in some movie plots (...) could be slightly out of distribution and it could have trouble generalizing. (...) (1:25:24) data mixture matters a lot and having points that are (...) sparse enough in the distribution space (...) rather than repeating the same story.

**한국어 번역**
SFT의 도전과제들:
1. **데이터 품질·비용**: 고품질 데이터에는 보통 사람이 개입(human in the loop)해야 하고, 사용자가 중시하는 규칙·특성을 다 지켜야 해 시간·자원이 많이 듭니다. (다만 한 번 만든 데이터셋은 재사용 가능)
2. **분포 정렬(distribution alignment)**: SFT 데이터의 분포가 실제 추론 시 들어올 분포와 맞아야 합니다. 예를 들어 교과서풍 이야기로만 학습했는데 영화 줄거리풍 이야기를 요청받으면, 분포에서 약간 벗어나(out of distribution) 일반화가 어려울 수 있습니다.
3. **일반화(generalization)**: 같은 이야기를 반복해 넣기보다, 분포 공간에서 충분히 흩어진(sparse) 다양한 예시를 줘야 모델이 핵심을 익혀 일반화합니다.

> 부수 논의: SFT 후 같은 입력을 다시 넣어도 (온도가 0이 아니라) 똑같은 출력은 안 나오고 '비슷한 결'이 나옵니다. 더 다양한 응답을 원하면 온도를 높이거나, 해당 범주의 데이터를 더 넣어 모델을 그 분포에 익숙하게 만들어야 합니다.

**용어 설명**
- **사람 개입(human in the loop)**: 데이터 작성·검수에 사람이 관여하는 것.
- **분포 정렬(distribution alignment)**: 학습 데이터 분포와 실제 입력 분포를 맞추는 것.
- **분포 이탈(out of distribution)**: 학습 때 못 본 유형의 입력. 일반화가 어려움.
- **일반화(generalization)**: 학습 예시를 넘어 새 입력에도 잘 작동하는 능력.

## 5. 복습 문제

1. 사전학습만 한 모델이 "세탁기에 넣어도 되냐"에 엉뚱하게 답하는 이유는? SFT는 이를 어떻게 바꾸는가?
2. SFT에서 입력 부분에는 왜 손실을 두지 않는가? instruction tuning이란 무엇인가?
3. SFT 데이터는 사전학습과 규모·성격이 어떻게 다른가? 분포 정렬·일반화가 왜 중요한가?

---

## 부록. 실무 적용 포인트 (NLP·LLM 기술 내용 한정)

- **SFT는 "왜 ChatGPT가 질문에 비서처럼 답하는가"의 답이다.** 사전학습만으로는 다음 단어를 잇기만 한다. 지시에 도움 되게 답하는 행동은 instruction tuning으로 입혀진 것이다. 즉 우리가 쓰는 LLM의 '비서다움'은 별도 학습 단계의 산물임을 이해하면, 모델 행동(거부·헤징 등)이 왜 그런지 납득된다.
- **분포 정렬·일반화는 "맞춤 데이터를 잘 골라야 한다"는 실무 지침이다.** 업무용으로 모델을 미세조정한다면, 실제 들어올 입력과 닮은 다양한 예시를 갖춰야 한다. 똑같은 사례만 반복하면 새 유형에 약해진다 — 봉화군 업무 맞춤 데이터 구성 시 유의점이다.
- **안전·거부 행동이 학습된 결과라는 점은 "AI의 거부에는 설계 의도가 있다"를 알려준다.** 모델이 어떤 요청을 거부하는 것은 안전 데이터로 학습된 행동이다. 도구의 거부·헤징 성향은 제품 결정의 일부이며, 업무 적합성을 따질 때 고려할 요소다.
